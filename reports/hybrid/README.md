# Terminal demonstration outputs

cli_guest.png and cli_profile.png are recorded executions on the shared 200-user, 200-game BGG sample. Both use 4 players and a 60-minute maximum. Enter selects guest ranking by training rating count. Profile 0 selects saved hybrid scores and excludes that user's training-rated games.

The sample screenshots illustrate program behavior. Final model metrics use the 20,000-user, 2,000-game experiment. The sample score file is outputs/scores.csv. Full experiment scores can be regenerated with make_top10.py.
